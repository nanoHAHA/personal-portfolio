# Personal IT Portfolio

Welcome to my personal IT portfolio project! This repository contains the source code for my web portfolio showcasing my projects, skills, and background as an IT student.

##  Project Overview
This project is built using HTML5 and CSS3 to deliver a clean, responsive, and modern layout. It highlights my capabilities in Web Development and Network Architecture.

##  Tech Stack & Features
- **Frontend:** HTML5, CSS3
- Key Features:
  - Modern hero header with profile presentation
  - Project showcase section with image previews
  - Fully structured and styled layout
